# -desarrollo_web_Juan_Erazo
repositorio para el desarrollo del ramo de desarrollo de aplicaciones web.

El codigo esta dividido en 4 archivos principales, estos son grafico.js, actividades.js, usuario.js y tarea_1_inline.html
cada uno de estos archivos tiene una funcion especifica, grafico.js se encarga de crear el grafico de pastel,
 actividades.js se encarga de manejar las actividades, usuario.js se encarga de manejar los usuarios y tarea_1_inline.html 
 es el archivo principal que contiene el html.

Supuestos:
            1. Los nombres utilizados son reales.
            2. Los ruts utilizados son reales.
            3. Las direcciones de correo utilizadas tienen dominios existentes.
            4. Los url's utilizados dirigen a una pagina o foto real.
            5. Las actividades ingresadas son reales.
            6. Las horas ingresadas son reales.
            7. no se repiten ruts al momento de crear usuarios.
            8. todas las actividades ingreadas pueden ser asignadas a un tipo de actividad existente.
            9. No se cuales son todos los posibles grados academicos asi que es un campo que se rellena en vez
               de ser un select.
